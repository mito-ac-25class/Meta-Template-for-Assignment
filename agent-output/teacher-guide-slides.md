# JavaScript課題 × GitHub Classroom

## 他教員向け授業ガイド

**役割分担**
- 担当教員：課題の作成・配布・採点設定（事前完了）
- **他教員：授業中の監督 ＋ 課題リンクの共有**

---

# 授業の全体フロー

```
担当教員（事前）   他教員（当日）    学生
    │                 │              │
    │ 課題を作成        │              │
    │ リンクを発行       │              │
    │───リンク共有──▶   │              │
    │                 │──リンク共有──▶ │
    │                 │              │ リポジトリが自動作成
    │                 │   （監督）     │ コードを書く
    │                 │              │ プッシュ → 自動採点
    │                 │              │ ✅ / ❌ を確認
```

---

# リポジトリの仕組み

| 要素 | 内容 |
|------|------|
| テンプレートリポジトリ | 課題のひな型 |
| 学生リポジトリ | `課題名-学籍番号` で自動作成 |
| `classroom.yml` | 自動採点CI（GitHub Actions） |
| `tests/` | 採点用テスト（PASS/FAIL） |
| `src/kadai/` | 学生がコードを書く場所 |

---

# 学生が授業中にやること

1. 📎 **課題リンクをクリック**  
   → 自分専用リポジトリが自動作成

2. 💻 **コードを実装**（`src/kadai/` 以下）

3. 📤 **コミット ＆ プッシュ**  
   → テストが自動実行される

4. ✅ **Actions タブで結果を確認**

5. ❌ なら修正して再プッシュ → 繰り返す

---

# 採点の仕組み

## プッシュ → 自動採点の流れ

```
学生がコードをプッシュ
        ↓
GitHub Actions が起動（classroom.yml）
        ↓
tests/ のテストが自動実行
        ↓
合格数に応じてスコアを記録
        ↓
GitHub Classroom 管理画面で一覧確認可能
```

**教員が手動で採点する必要はありません** ✨

---

# 監督中に対応できること

| 状況 | 対応 |
|------|------|
| リンクを知らない学生がいる | リンクを再共有 |
| 「テストが赤い」と相談された | Actions タブのログを一緒に確認 |
| リポジトリが見つからない | 組織ページで検索 |
| 提出状況を確認したい | Classroom 管理画面で確認 |
| 課題内容の質問 | 担当教員に確認を促す |

---

# Actions タブの見方

学生のリポジトリ → **「Actions」タブ**

- ✅ 緑のチェック = **合格**
- ❌ 赤の × = **未完成**（ログでどのテストが失敗か確認可能）

![Actions tab image](https://docs.github.com/assets/cb-15760/images/help/repository/actions-tab.png)

> 🎯 学生はリンクを踏んでコードを書いてプッシュするだけ  
> 🤖 採点は GitHub Actions が自動で実施

>

# 緊急時の連絡先

授業中に解決できない問題が発生した場合は、**担当教員に連絡**してください。

- リポジトリのトラブル
- 課題の内容に関する質問
- GitHub Classroom の設定変更が必要な場合
