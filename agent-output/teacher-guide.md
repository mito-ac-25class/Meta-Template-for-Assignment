# 他教員向け説明資料：JavaScript課題 × GitHub Classroom 授業ガイド

## 概要

本授業はオムニバス形式で進行するJavaScript課題の授業です。  
課題の作成・配布は担当教員が事前に行い、他教員は**授業中の監督**および**課題リンクの共有**を担当します。

---

## 授業の全体フロー

```
担当教員（事前準備）         他教員（授業当日）          学生
        │                         │                    │
        │ 課題をGitHub Classroomで作成                  │
        │ 課題リンクを発行          │                    │
        │                         │                    │
        │──── 課題リンクを共有 ────▶│                    │
        │                         │──── リンクを共有 ──▶│
        │                         │                    │ リポジトリが自動作成される
        │                         │                    │ コードを実装する
        │                         │      （監督）        │ コミット＆プッシュ
        │                         │                    │
        │                         │                    │ テストが自動実行される
        │ GitHub Classroomで採点結果を確認              │ 結果を確認
```

---

## リポジトリの仕組み

| 要素 | 内容 |
|------|------|
| **テンプレートリポジトリ** | 課題のひな型。学生がリンクを踏むと自分専用コピーが自動作成される |
| **学生リポジトリ** | `課題名-学籍番号` の形で自動作成される（例：`js-kadai-tanaka`） |
| **`.github/workflows/classroom.yml`** | プッシュのたびに自動採点するCI（GitHub Actionsで動作） |
| **`tests/`** | 採点用テスト。学生コードが正しければPASS、誤りはFAIL |
| **`src/kadai/`** | 学生が実際にJavaScriptコードを書く場所 |

---

## 学生が授業中に行うこと

1. **課題リンクをクリック**  
   → 自分専用のリポジトリが GitHub 上に自動作成される

2. **リポジトリを PC にクローン** または GitHub Web Editor / Codespaces を開く

3. **`src/kadai/` 以下にコードを実装**  
   → 課題の指示（README）に従ってJavaScriptを書く

4. **コミット＆プッシュ**  
   → 保存のたびにテストが自動実行される

5. **GitHub の「Actions」タブで結果を確認**  
   → 緑のチェック ✅ = 合格 / 赤の × ❌ = 未完成

6. 合格するまで 3〜5 を繰り返す

---

## 他教員が授業中に対応できること

| 状況 | 対応方法 |
|------|---------|
| 学生が課題リンクを知らない | LMS・チャット等で共有された課題リンクを再共有 |
| 「テストが赤い」と相談された | 「Actions タブのログを見て、失敗しているテストを確認して」と誘導 |
| リポジトリが見つからない | GitHub Classroom の組織ページで `課題名-学籍番号` を検索 |
| 提出状況を確認したい | GitHub Classroom 管理画面 → 課題一覧 → 提出状況で確認可能 |
| 課題の内容に関する質問 | 担当教員に確認するよう誘導（課題設計は担当教員が実施） |

---

## 採点の仕組み（自動採点）

- 学生がコードをプッシュするたびに **GitHub Actions** が起動
- `tests/` 内のテストが自動実行され、合格数に応じてスコアが記録される
- **GitHub Classroom の管理画面**で全学生の提出状況・スコアを一覧確認できる
- 教員が手動で採点する必要はない（最終確認のみ）

---

## まとめ（監督教員へ）

> 学生は GitHub の課題リンクを踏み、コードを書いてプッシュするだけで自動採点されます。  
> 監督は「学生が詰まっていないか」を見回り、困っていたら Actions のエラーログを一緒に確認してあげてください。  
> **課題配布・採点設定はすべて事前に済んでいます。**
