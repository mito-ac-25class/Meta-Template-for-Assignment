| ステージ | 機能                                                | 受け入れ条件（テスト観点）                                    | 点数   |
|--------|----------------------------------------------------------|------------------------------------------------------------ |--------|
| 1      | 銀行口座クラスが存在する                                                | `BankAccount` クラスが存在する                                                                          | 10       |

### 動作例
```py
taro = BankAccount("Taro", 1000, "123456789")
hanako = BankAccount("Hanako", 0, "987654321")

taro.deposit(400)
print(taro.balance) # 600

taro.transfer_to(hanako, 250)

print(taro.balance) # 350
print(hanako.balance) # 250
```

### 早く終わってしまったら

- 異常な金額の入出金や口座振替に対して `ValueError` 例外を出せるようにしてみよう
- コンストラクタのデフォルト値を設定し、クラス変数を合わせて口座番号を自動採番出来るようにしてみよう
- どちらも、テストを記述 -> テストに失敗 -> 実装 -> テスト通過を確認 の順で実装してみよう

## トラブルシューティング

- **前段階のテストに通らなくなった**:  
  復旧が難しければ、以下の手順でひとつ前のコミットに戻しましょう。

    - ひとつ前のコミットに戻すとき:  
      ソース管理 → 「変更を破棄」(曲がった矢印マーク) → 破棄しますか？のメッセージに「ファイルの破棄」
    
    - ふたつ以上前のコミットに戻すとき:
      1. ソース管理 →　「変更」にある 「…」 にカーソル
      2. 戻したいコミットまで、コミット (Commit) → 前回のコミットを元に戻す (Undo Last Commit) を選択
      3. 変更がステージされた状態なので、「変更のステージング解除」(－マーク)
      4. 変更されたファイルを選択し、「変更を破棄」(曲がった矢印マーク)
